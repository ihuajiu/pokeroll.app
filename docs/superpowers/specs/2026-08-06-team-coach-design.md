# Team Coach（补队教练）设计

> 日期：2026-08-06
> 状态：已与用户逐节确认（第 1-4 节）
> 入口：独立页面 `/team/coach`

## 1. 概述

休闲向"补队"工具：用户已选定 1-5 只宝可梦，工具用**覆盖导向 + 角色多样**的规则把队伍补满（默认 6 只），每只补的宝可梦带一句**推荐理由**，可单格重摇、整体重补、加入队伍、分享复现。

**不做**竞技 meta（Smogon 分级 / 配招 / 努力值 / 性格）。

## 2. 用户流程（第 1 节确认）

```
Team Coach — fill your team
How to play: ① 添加已选宝可梦 ② 补全 ③ 微调入队

步骤一  添加已选（锁定区，最多 5 只）
  [搜索框…] [从收藏夹导入] [从队伍导入]
  锁定卡 HeroCard（team 变体，无 New roll，可移除 ×）

步骤二  [ 补全队伍 ]（≥1 只锁定可用）· 目标尺寸下拉 3-6（默认 6）

步骤三  补的卡 + 理由标签 + ↻单格重摇（另：全部重补）

步骤四  [加入我的队伍] [分享补队结果]
```

### 关键交互
- **锁定区**：搜索联想添加；一键从收藏夹（useFavorites）导入；一键从我的队伍（useTeam）导入；每张可移除；最多锁 5 只（补到 6）。
- **补全**：≥1 只锁定即可点"补全队伍"，生成剩余位置。
- **理由标签**：每张补的卡一个小标签，说明为什么选它（挡弱点 / 补类型 / 补角色）。
- **微调**：每张补的卡有"↻ 单格重摇"；另有"全部重补"。
- **目标尺寸**：默认 6，可调 3-6。
- **校验**：锁定数量必须小于目标尺寸（至少留 1 个补位），否则提示并禁用补全。

## 3. 补队算法（第 2 节确认，服务端 lib/teamCoach.ts）

输入：locked（已锁定）+ keep（保留的补位，单格重摇用）+ count + 筛选（gen/region/type）+ seed。

候选池：全图鉴筛选后排除已锁定/已保留（避免重复）。

打分维度（对每个候选，按当前队伍状态实时计算）：
| 维度 | 逻辑 |
|---|---|
| 类型去重 | 主类型与队伍已有重复 → 扣分（兜底时允许） |
| 补抗性 | 汇总队伍被克制的弱点类型，候选能抵抗/免疫 → 加分 |
| 补覆盖 | 候选提供队伍缺少的攻击覆盖 → 加分 |
| 角色多样 | 按 stats 粗分角色（高速手/耐久坦克/物攻/特攻/均衡），队伍缺口 → 加分 |

生成：种子 RNG + 按分数加权的随机抽签（非硬选最优，保留随机感），逐只填充；每填一只更新"队伍已有"集合，下一只按更新后队伍重新打分（互相补位）。

理由标签：取该候选得分最高维度生成一句：
- `🛡 挡{属性}弱点` / `🎯 补{属性}覆盖` / `🚀 高速手` / `🛡 耐久位` / `⚔️ 物攻手` / `✨ 特攻手`

兜底：窄筛选候选不足 → 逐级放宽（先去筛选，再允许类型重复），保证总能补满。

打分权重集中为常量，便于调优。

## 4. 数据与 API（第 3 节确认）

**lib/teamCoach.ts（服务端纯函数）**
`completeTeam({ locked, keep, count, filters, seed }) → { team: Pokemon[], reasons: Record<dex, string> }`
- 复用 lib/team.ts 的种子 RNG、getAllPokemon、筛选逻辑。

**API `/api/team/coach`**
`?locked=25,6&keep=94&count=6&gen=&region=&type=&seed= → { seed, team, reasons }`
- 初始补全：keep 空；单格重摇：keep = 除该格外的所有卡；全部重补：keep 空 + 新 seed。

**页面 /team/coach**
- 服务端组件解析分享参数（locked/count/seed）→ 初始补队结果传给客户端组件 `TeamCoach.tsx`。
- 客户端：锁定区添加/移除 → 调 API 补全 → 展示卡片 + 理由 → 单格重摇/全部重补 → 加入队伍 → 分享。

**分享与可复现**
- 每次补全/重摇产生新 seed 并同步到 URL（`/team/coach?locked=25,6&count=6&seed=abc`）。
- 对方打开 → 服务端用相同 locked + seed 重新计算 → 同样补队结果（与 wheel 分享一致）。

## 5. 范围与集成（第 4 节确认）

- 入口：lib/tools.ts team 分组（Header "Team" 下拉、首页浏览、RelatedTools 自动出现）；加入 sitemap。
- 筛选：gen / region / type（复用 team/random 筛选控件样式），影响候选池。
- 卡片：HeroCard team 变体；补的卡带理由标签 + 单格重摇 + 收藏/分享/下载；锁定卡可移除、无 New roll。
- 底部：加入我的队伍（整体，useTeam）+ 分享补队结果。

**明确不做（YAGNI）**
- 竞技 meta（分级/配招/努力值/性格）
- 逐步向导、多方案对比
- 完整弱点矩阵/联防分析面板（仅理由标签）
- 按能力值精确配队（仅 bst/stats 粗分角色）

## 6. 成功标准

- 用户锁定 1-5 只 → 一键补满 6 只。
- 每只补的卡有清晰理由，队伍类型/角色明显比纯随机合理。
- 可单格微调、可加入队伍、可分享复现。
